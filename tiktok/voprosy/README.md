# Вопросы зрителей

Комментарии TikTok автоматически не собрать: на открытых страницах роликов их нет.
Поэтому каждую пятницу разбор присылает ссылки на 5 хитов недели, а скриншоты
комментариев под ними присылаются в чат. Из них выписываются вопросы и
предлагаются посты: `nedelya-<дата>.json` с полями
date, text и items[title, format, why, questions, shots, caption].
Последний файл попадает на общую страницу в раздел «Посты по вопросам зрителей».
