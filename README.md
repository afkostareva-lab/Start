# Люмен — контент-стратегия

Проект: обучение внедрению ИИ в рутинную работу офисных менеджеров.
Продукт: разовые консультации-разборы. Площадки: Telegram + Instagram Reels.

## Файлы

- **`lumen-strategy.html`** — конкурентный анализ ниши и полная контент-стратегия.
  Разбор трёх тиров конкурентов (онлайн-школы, телеграм-каналы, B2B-интеграторы),
  найденная рыночная дыра, позиционирование, пять рубрик, воронка на заявки,
  план на шесть недель, режим производства и метрики. Опубликовано как артефакт.
- **`kontent-plan.md`** — рабочая версия плана для планировщика: рубрики,
  шесть недель с готовыми темами, лид-магнит, режим съёмки, метрики.

## Главный вывод анализа

Занята ниша инструментов («какая нейросеть лучше») и ниша корпоративного
внедрения. Между ними — дыра: конкретному менеджеру никто не показывает,
какие из его повторяющихся задач вообще можно отдать ИИ. Именно об это
спотыкаются 44% тех, кто не пользуется нейросетями. Люмен продаёт ответ
на этот вопрос, поэтому контент строится вокруг задачи из рабочей недели,
а не вокруг инструмента.
