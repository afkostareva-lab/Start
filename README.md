# Люмен — контент-стратегия и воронка

Проект: обучение внедрению ИИ в рутинную работу офисных менеджеров.
Продукт: разовые консультации-разборы. Площадки: Telegram + Instagram Reels.

## Стратегия

- **`lumen-strategy.html`** — конкурентный анализ ниши и контент-стратегия.
  Три тира конкурентов (онлайн-школы, телеграм-каналы, B2B-интеграторы), найденная
  рыночная дыра, позиционирование, пять рубрик, воронка, план на шесть недель,
  режим производства и метрики.
- **`kontent-plan.md`** — рабочая версия плана для планировщика.

## Воронка: готовые продукты

- **`docs/index.html`** — та же карта, собранная как самостоятельная страница для
  GitHub Pages: открывается у любого человека без аккаунта и установки. Генерируется
  из `karta-rutiny.html` скриптом `build-docs.py` — после правки карты запусти его.
  Опубликована: **https://afkostareva-lab.github.io/Start/** — обновляется
  автоматически при каждом пуше в ветку.
- **`karta-rutiny.html`** — лид-магнит. Интерактивная диагностика рабочей недели:
  человек вносит повторяющиеся задачи, отмечает три признака и получает разбор —
  что отдавать сегодня, что после подготовки, что не трогать, — плюс оценку
  освобождаемых часов. Перед таблицей — шестнадцать разобранных задач с готовыми запросами
  и фильтром по профессии: офис и продажи, психологи, репетиторы.
  Считает в браузере, сохраняется локально, работает с телефона.
- **`karta-rutiny.xlsx`** — тот же инструмент таблицей, для выдачи файлом из бота.
  Формулы, выпадающие списки, подсветка кандидатов, итоговый блок. Второй лист
  «Примеры» — те же шестнадцать разборов с колонкой профессии.
- **`bot-stsenarii.md`** — все тексты бота (семь сообщений цепочки), схема воронки,
  тексты призывов для постов, ответы на возражения и порядок настройки.
- **`nastroyka-bota.html`** — пошаговая сборка бота: семь шагов с отметками
  о выполнении, готовыми текстами по кнопке «копировать» и разбором частых
  поломок. Для того, кто настраивает всё это руками первый раз.

## Главный вывод анализа

Занята ниша инструментов («какая нейросеть лучше») и ниша корпоративного внедрения.
Между ними — дыра: конкретному менеджеру никто не показывает, какие из его
повторяющихся задач вообще можно отдать ИИ. Именно об это спотыкаются 44% тех,
кто не пользуется нейросетями. Люмен продаёт ответ на этот вопрос, поэтому контент
строится вокруг задачи из рабочей недели, а не вокруг инструмента.
